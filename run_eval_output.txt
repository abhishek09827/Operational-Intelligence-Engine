│  ### 3.1 Primary Root Cause                                                                                                                                                                                                                                                          │
│                                                                                                                                                                                                                                                                                      │
│  The **definitive root cause** is a **credential mismatch**: the `db-pool` service is configured with an incorrect password for the `postgres` user. PostgreSQL correctly rejected the authentication request, as evidenced by the `FATAL` error. This is a configuration issue,     │
│  not a software bug or resource constraint.                                                                                                                                                                                                                                          │
│                                                                                                                                                                                                                                                                                      │
│  ### 3.2 Contributing Factors                                                                                                                                                                                                                                                        │
│                                                                                                                                                                                                                                                                                      │
│  The `Connection refused` error is a secondary effect. It likely occurred because:                                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                                                      │
│  - After repeated authentication failures, the database administrator or automated tooling stopped the PostgreSQL service to investigate, causing subsequent connection attempts to be refused.                                                                                      │
│  - The database may have temporarily exhausted its connection limit due to the pool repeatedly trying to connect with invalid credentials, causing `connection refused` conditions.                                                                                                  │
│  - A transient network or server availability issue (e.g., PostgreSQL restart) coincided with the authentication failure.                                                                                                                                                            │
│                                                                                                                                                                                                                                                                                      │
│  ### 3.3 Possible Sources of the Password Mismatch                                                                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                                                      │
│  - **Password rotation:** A recent administrative password change for the `postgres` user was not propagated to the `db-pool` configuration.                                                                                                                                         │
│  - **Environment variable misconfiguration:** `DB_PASSWORD` or similar environment variable was not set correctly or was updated with an outdated value.                                                                                                                             │
│  - **Manual configuration error:** A typo, leading/trailing whitespace, or an escape character in the password string within the configuration file.                                                                                                                                 │
│  - **Authentication method incompatibility:** The server expects `scram-sha-256`, but the client is attempting to authenticate using `md5`, leading to a password verification failure even if the password is technically correct.                                                  │
│                                                                                                                                                                                                                                                                                      │

│  - **Hidden operational issues**: Without logs, any concurrent errors or anomalies in the storage subsystem may go undetected.                                                                                                                                                       │
│  - **System-wide degradation**: In worst-case scenarios, a full filesystem can affect other services that share the `/var/log` mount (e.g., systemd journal, auditd, other applications).                                                                                            │
│                                                                                                                                                                                                                                                                                      │

│  ## 3. Root Cause Analysis                                                                                                                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  ### 3.1 Immediate Cause                                                                                                                                                                                                                                                             │
│                                                                                                                                                                                                                                                                                      │
│  The filesystem mounted at `/var/log` was **100% utilized**, leaving zero writable blocks. The storage-node service's attempt to write a log entry failed with `ENOSPC`.                                                                                                             │
│                                                                                                                                                                                                                                                                                      │
│  ### 3.2 Contributing Factors (Likely Root Causes)                                                                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                                                      │
│  The table below summarizes the potential contributing factors, ranked by likelihood, along with their mechanism of action:                                                                                                                                                          │
│                                                                                                                                                                                                                                                                                      │
│  | # | Root Cause | Mechanism |                                                                                                                                                                                                                                                      │
│  |---|------------|-----------|                                                                                                                                                                                                                                                      │
│  | 1 | **Inadequate or misconfigured log rotation** | `logrotate` (or equivalent) absent, or configured with overly long retention, no compression, or too-frequent rotation. Log files grow unboundedly, eventually exhausting disk space. |                                        │
│  | 2 | **Unusually high log generation rate** | The service may be in a logging loop (bug), running with `DEBUG` level in production, or under stress (e.g., network errors, I/O failures) causing excessive log writes. |                                                           │
│  | 3 | **Insufficient storage allocation for `/var/log`** | The partition was undersized during capacity planning. Even normal logging volume exceeds the available space over time. |                                                                                               │
│  | 4 | **Presence of unrelated large files in `/var/log`** | Core dumps, stale rotated archives, or oversized system logs (e.g., kernel logs, audit logs) may be consuming disproportionate space. |                                                                                 │
│  | 5 | **Log forwarder buffer spill** | A log shipper (fluentd, filebeat, syslog-ng) may be buffering logs locally in `/var/log`, filling the partition with queued messages. |                                                                                                      │
│  | 6 | **Symlink misconfiguration** | If the log file is a symlink to a location on another full filesystem, the space exhaustion may be masked until the error surfaces. |                                                                                                          │
│                                                                                                                                                                                                                                                                                      │
│  ### 3.3 Fundamental / Systemic Cause                                                                                                                                                                                                                                                │
│                                                                                                                                                                                                                                                                                      │
│  The **root cause** is a failure in **log management and capacity governance**. The system lacked:                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                                                      │
│  - **Proactive monitoring**: No alert triggered when `/var/log` crossed safe thresholds (e.g., 80% utilization), allowing the condition to silently escalate to 100%.                                                                                                                │
│  - **Automated log lifecycle policies**: Rotation, compression, and archival were not enforced or were ineffective.                                                                                                                                                                  │
│  - **Resource limits / quotas**: No disk usage quota or log volume cap was applied to the service, and the partition size was inadequate for actual demand.                                                                                                                          │
│                                                                                                                                                                                                                                                                                      │
│  Had any one of these safeguards existed, the disk would have been pruned before reaching 100%, or an alert would have allowed manual intervention before the service failed.                                                                                                        │

│  ## 4. Recommended Fixes                                                                                                                                                                                                                                                             │
│                                                                                                                                                                                                                                                                                      │
│  The following fixes are ordered for immediate execution. Step 1 and Step 2 restore service; Steps 3–6 prevent recurrence.                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  ### Step 1: Immediate Space Recovery                                                                                                                                                                                                                                                │
│                                                                                                                                                                                                                                                                                      │
│  Identify and remove space-hogging files:                                                                                                                                                                                                                                            │
│                                                                                                                                                                                                                                                                                      │
│  ```bash                                                                                                                                                                                                                                                                             │
│  # Identify largest files in /var/log                                                                                                                                                                                                                                                │
│  du -h /var/log/* | sort -rh | head -20                                                                                                                                                                                                                                              │
│                                                                                                                                                                                                                                                                                      │
│  # Force rotation/compression for the storage-node log                                                                                                                                                                                                                               │
│  sudo logrotate --force /etc/logrotate.d/storage-node                                                                                                                                                                                                                                │
│                                                                                                                                                                                                                                                                                      │
│  # Manual fallback: compress old logs and truncate current                                                                                                                                                                                                                           │
│  sudo gzip /var/log/storage-node.log.old                                                                                                                                                                                                                                             │
│  sudo truncate -s 0 /var/log/storage-node.log                                                                                                                                                                                                                                        │
│                                                                                                                                                                                                                                                                                      │
│  # Delete rotated logs older than 7 days                                                                                                                                                                                                                                             │
│  sudo find /var/log -name "*.gz" -o -name "*.1" -o -name "*.old" -mtime +7 -delete                                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                                                      │
│  # Find and remove large files (e.g., core dumps) — confirm before deletion                                                                                                                                                                                                          │
│  sudo find /var/log -type f -size +100M -exec ls -lh {} \;                                                                                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  # Verify freed space                                                                                                                                                                                                                                                                │
│  df -h /var/log                                                                                                                                                                                                                                                                      │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ### Step 2: Restart Service                                                                                                                                                                                                                                                         │
│                                                                                                                                                                                                                                                                                      │
│  ```bash                                                                                                                                                                                                                                                                             │
│  sudo systemctl restart storage-node                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  # Monitor for the first few minutes to ensure no immediate re-fill                                                                                                                                                                                                                  │
│  sudo journalctl -u storage-node -f --since "5 minutes ago"                                                                                                                                                                                                                          │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ### Step 3: Configure Proper Log Rotation                                                                                                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  Create `/etc/logrotate.d/storage-node`:                                                                                                                                                                                                                                             │
│                                                                                                                                                                                                                                                                                      │
│  ```bash                                                                                                                                                                                                                                                                             │
│  sudo tee /etc/logrotate.d/storage-node <<EOF                                                                                                                                                                                                                                        │
│  /var/log/storage-node.log {                                                                                                                                                                                                                                                         │
│      daily                                                                                                                                                                                                                                                                           │
│      rotate 7                                                                                                                                                                                                                                                                        │
│      compress                                                                                                                                                                                                                                                                        │
│      delaycompress                                                                                                                                                                                                                                                                   │
│      missingok                                                                                                                                                                                                                                                                       │
│      notifempty                                                                                                                                                                                                                                                                      │
│      create 0640 storage-node storage-node                                                                                                                                                                                                                                           │
│      sharedscripts                                                                                                                                                                                                                                                                   │
│      postrotate                                                                                                                                                                                                                                                                      │
│          /usr/bin/systemctl reload storage-node > /dev/null 2>&1 || true                                                                                                                                                                                                             │
│      endscript                                                                                                                                                                                                                                                                       │
│  }                                                                                                                                                                                                                                                                                   │
│  EOF                                                                                                                                                                                                                                                                                 │

│  # Apply immediately and verify                                                                                                                                                                                                                                                      │
│  sudo logrotate --force /etc/logrotate.d/storage-node                                                                                                                                                                                                                                │
│  sudo logrotate --debug /etc/logrotate.d/storage-node                                                                                                                                                                                                                                │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  **Configuration rationale**:                                                                                                                                                                                                                                                        │
│  - `daily`: rotate once per day                                                                                                                                                                                                                                                      │
│  - `rotate 7`: keep one week of logs                                                                                                                                                                                                                                                 │
│  - `compress`: gzip rotated files to reduce disk footprint                                                                                                                                                                                                                           │
│  - `delaycompress`: delay compression by one rotation to keep the latest rotated file uncompressed (avoids issues with open file handles)                                                                                                                                            │
│  - `postrotate`: signal the service to reload/reopen its log file                                                                                                                                                                                                                    │

│                                                                                                                                                                                                                                                                                      │

│      level: INFO  # was DEBUG                                                                                                                                                                                                                                                        │
│      file: /var/log/storage-node.log                                                                                                                                                                                                                                                 │
│    ```                                                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│  - **Implement rate limiting** in the logging framework or via `journald`:                                                                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │

│    ```                                                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│  - **Or move logs to a larger filesystem** and symlink:                                                                                                                                                                                                                              │
│                                                                                                                                                                                                                                                                                      │
│    ```bash                                                                                                                                                                                                                                                                           │
│    sudo mkdir -p /data/logs                                                                                                                                                                                                                                                          │
│    sudo chown storage-node:storage-node /data/logs                                                                                                                                                                                                                                   │

│    sudo ln -s /data/logs/storage-node.log /var/log/storage-node.log                                                                                                                                                                                                                  │
│    ```                                                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│  - **Capacity estimation**: Monitor daily log growth for several days and allocate at least 2x the maximum daily volume.                                                                                                                                                             │
│                                                                                                                                                                                                                                                                                      │
│  ### Step 6: Implement Monitoring and Alerting                                                                                                                                                                                                                                       │
│                                                                                                                                                                                                                                                                                      │
│  - **Prometheus alert rule** (with Node Exporter):                                                                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                                                      │

│    - alert: HighLogDiskUsage                                                                                                                                                                                                                                                         │
│      expr: (node_filesystem_avail_bytes{mountpoint="/var/log"} / node_filesystem_size_bytes{mountpoint="/var/log"}) * 100 < 20                                                                                                                                                       │

│      labels:                                                                                                                                                                                                                                                                         │
│        severity: warning                                                                                                                                                                                                                                                             │
│      annotations:                                                                                                                                                                                                                                                                    │

│    ```                                                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│  - **Cron-based check** (fallback):                                                                                                                                                                                                                                                  │
│                                                                                                                                                                                                                                                                                      │

│    # Add to crontab (every 10 minutes)                                                                                                                                                                                                                                               │
│    */10 * * * * root /usr/bin/df --output=pcent /var/log | tail -1 | awk '{if ($1 > 80) print "WARNING: /var/log at "$1" usage"}' | mail -s "Disk Alert" ops@example.com                                                                                                             │
│    ```                                                                                                                                                                                                                                                                               │

│      @CircuitBreaker(name = "paymentProvider", fallbackMethod = "paymentProviderFallback")                                                                                                                                                                                           │
│      public PaymentResult charge(PaymentRequest request) {                                                                                                                                                                                                                           │
│          ResponseEntity<PaymentResult> response = restTemplate.postForEntity(                                                                                                                                                                                                        │
│                  "https://payment-provider.example.com/charge",                                                                                                                                                                                                                      │
│                  request,                                                                                                                                                                                                                                                            │
│                  PaymentResult.class                                                                                                                                                                                                                                                 │
│          );                                                                                                                                                                                                                                                                          │
│          return response.getBody();                                                                                                                                                                                                                                                  │
│      }                                                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│      public PaymentResult paymentProviderFallback(PaymentRequest request, Throwable t) {                                                                                                                                                                                             │
│          // Return a fast failure response, or throw a controlled exception that maps to HTTP 503                                                                                                                                                                                    │
│          throw new PaymentProviderUnavailableException("Payment provider is unavailable", t);                                                                                                                                                                                        │
│      }                                                                                                                                                                                                                                                                               │
│  }                                                                                                                                                                                                                                                                                   │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  Now a failing payment provider becomes an open circuit in under a second; the worker thread is not left blocked on a hung call.                                                                                                                                                     │
│                                                                                                                                                                                                                                                                                      │
│  ---                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ## 4. Add Bulkheads to Isolate Dependencies                                                                                                                                                                                                                                         │
│                                                                                                                                                                                                                                                                                      │
│  Bulkheads limit how many threads can be used by a given dependency. A slow payment provider can only exhaust its own small pool, not the whole service.                                                                                                                             │
│                                                                                                                                                                                                                                                                                      │
│  ### Semaphore bulkhead (simple, non-blocking)                                                                                                                                                                                                                                       │
│                                                                                                                                                                                                                                                                                      │
│  ```yaml                                                                                                                                                                                                                                                                             │
│  resilience4j:                                                                                                                                                                                                                                                                       │
│    bulkhead:                                                                                                                                                                                                                                                                         │
│      instances:                                                                                                                                                                                                                                                                      │
│        paymentProvider:                                                                                                                                                                                                                                                              │
│          max-concurrent-calls: 10                                                                                                                                                                                                                                                    │
│          max-wait-duration: 0                                                                                                                                                                                                                                                        │
│        paymentDatabase:                                                                                                                                                                                                                                                              │
│          max-concurrent-calls: 20                                                                                                                                                                                                                                                    │
│          max-wait-duration: 0                                                                                                                                                                                                                                                        │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  Use `@Bulkhead` on the same service methods:                                                                                                                                                                                                                                        │
│                                                                                                                                                                                                                                                                                      │
│  ```java                                                                                                                                                                                                                                                                             │
│  @Bulkhead(name = "paymentProvider")                                                                                                                                                                                                                                                 │
│  @CircuitBreaker(name = "paymentProvider", fallbackMethod = "paymentProviderFallback")                                                                                                                                                                                               │
│  public PaymentResult charge(PaymentRequest request) {                                                                                                                                                                                                                               │
│      // ...                                                                                                                                                                                                                                                                          │
│  }                                                                                                                                                                                                                                                                                   │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ### Thread pool bulkhead (stronger isolation)                                                                                                                                                                                                                                       │
│                                                                                                                                                                                                                                                                                      │
│  If the service uses thread-per-request, this is the more protective option:                                                                                                                                                                                                         │
│                                                                                                                                                                                                                                                                                      │
│  ```yaml                                                                                                                                                                                                                                                                             │
│  resilience4j:                                                                                                                                                                                                                                                                       │
│    thread-pool-bulkhead:                                                                                                                                                                                                                                                             │
│      instances:                                                                                                                                                                                                                                                                      │
│        paymentProvider:                                                                                                                                                                                                                                                              │
│          max-thread-pool-size: 4                                                                                                                                                                                                                                                     │
│          core-thread-pool-size: 4                                                                                                                                                                                                                                                    │
│          queue-capacity: 2                                                                                                                                                                                                                                                           │
│          keep-alive-duration: 20s                                                                                                                                                                                                                                                    │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  With a thread pool bulkhead, a payment provider stall can only tie up 4 worker threads instead of the entire Tomcat or Jetty thread pool.                                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  ---                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ## 5. Fix Connection Leaks and Slow Queries                                                                                                                                                                                                                                         │
│                                                                                                                                                                                                                                                                                      │
│  If the downstream dependency was a database, leaks and slow queries directly caused thread exhaustion.                                                                                                                                                                              │
│                                                                                                                                                                                                                                                                                      │
│  ### Use `try-with-resources` everywhere                                                                                                                                                                                                                                             │
│                                                                                                                                                                                                                                                                                      │
│  ```java                                                                                                                                                                                                                                                                             │
│  public Optional<PaymentOrder> findOrderById(Long orderId) {                                                                                                                                                                                                                         │
│      String sql = "SELECT * FROM payment_orders WHERE id = ?";                                                                                                                                                                                                                       │
│                                                                                                                                                                                                                                                                                      │
│      try (Connection conn = dataSource.getConnection();                                                                                                                                                                                                                              │
│           PreparedStatement ps = conn.prepareStatement(sql)) {                                                                                                                                                                                                                       │
│                                                                                                                                                                                                                                                                                      │
│          ps.setLong(1, orderId);                                                                                                                                                                                                                                                     │
│          ps.setQueryTimeout(3);                                                                                                                                                                                                                                                      │
│                                                                                                                                                                                                                                                                                      │
│          try (ResultSet rs = ps.executeQuery()) {                                                                                                                                                                                                                                    │
│              if (rs.next()) {                                                                                                                                                                                                                                                        │
│                  return Optional.of(map(rs));                                                                                                                                                                                                                                        │
│              }                                                                                                                                                                                                                                                                       │
│          }                                                                                                                                                                                                                                                                           │
│      } catch (SQLException e) {                                                                                                                                                                                                                                                      │
│          throw new DatabaseUnavailableException("Database query failed", e);                                                                                                                                                                                                         │
│      }                                                                                                                                                                                                                                                                               │
│      return Optional.empty();                                                                                                                                                                                                                                                        │
│  }                                                                                                                                                                                                                                                                                   │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ### Find and fix slow queries                                                                                                                                                                                                                                                       │
│                                                                                                                                                                                                                                                                                      │
│  During the incident window, look for:                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│  - Sequential scans on large tables                                                                                                                                                                                                                                                  │
│  - Lock contention                                                                                                                                                                                                                                                                   │
│  - Missing indexes                                                                                                                                                                                                                                                                   │
│  - N+1 query patterns                                                                                                                                                                                                                                                                │
│                                                                                                                                                                                                                                                                                      │
│  Add the missing indexes or rewrite the queries. Enable Hikari leak detection to catch unreturned connections:                                                                                                                                                                       │
│                                                                                                                                                                                                                                                                                      │
│  ```yaml                                                                                                                                                                                                                                                                             │
│  spring:                                                                                                                                                                                                                                                                             │
│    datasource:                                                                                                                                                                                                                                                                       │
│      hikari:                                                                                                                                                                                                                                                                         │
│        leak-detection-threshold: 5000                                                                                                                                                                                                                                                │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ---                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ## 6. Align Gateway Timeout with the Service’s Real Performance Budget                                                                                                                                                                                                              │
│                                                                                                                                                                                                                                                                                      │
│  The gateway timeout should be **longer** than every internal timeout and **shorter** than the client-facing SLO.                                                                                                                                                                    │
│                                                                                                                                                                                                                                                                                      │
│  ### Spring Cloud Gateway                                                                                                                                                                                                                                                            │
│                                                                                                                                                                                                                                                                                      │
│  ```yaml                                                                                                                                                                                                                                                                             │
│  spring:                                                                                                                                                                                                                                                                             │
│    cloud:                                                                                                                                                                                                                                                                            │
│      gateway:                                                                                                                                                                                                                                                                        │
│        httpclient:                                                                                                                                                                                                                                                                   │
│          connect-timeout: 2000                                                                                                                                                                                                                                                       │
│          response-timeout: 10s                                                                                                                                                                                                                                                       │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ### Nginx / ingress-nginx                                                                                                                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  ```nginx                                                                                                                                                                                                                                                                            │
│  proxy_connect_timeout 3s;                                                                                                                                                                                                                                                           │
│  proxy_read_timeout 10s;                                                                                                                                                                                                                                                             │
│  proxy_send_timeout 10s;                                                                                                                                                                                                                                                             │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  This gives `payments-service` 10 seconds to respond. Since internal timeouts are 3 seconds, a slow dependency will fail well before the gateway gives up.                                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  ---                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  ## 7. Make Health Checks Detect Thread Pool Saturation                                                                                                                                                                                                                              │
│                                                                                                                                                                                                                                                                                      │
│  A readiness probe that only checks process liveness is not enough. Add an application-level health indicator that checks the thread pool and dependency circuit breakers.                                                                                                           │
│                                                                                                                                                                                                                                                                                      │
│  Example Spring Boot health indicator:                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│  ```java                                                                                                                                                                                                                                                                             │
│  @Component                                                                                                                                                                                                                                                                          │
│  public class ThreadPoolHealthIndicator implements HealthIndicator {                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│      private final ThreadPoolTaskExecutor taskExecutor;                                                                                                                                                                                                                              │
│                                                                                                                                                                                                                                                                                      │
│      public ThreadPoolHealthIndicator(ThreadPoolTaskExecutor taskExecutor) {                                                                                                                                                                                                         │
│          this.taskExecutor = taskExecutor;                                                                                                                                                                                                                                           │
│      }                                                                                                                                                                                                                                                                               │
│                                                                                                                                                                                                                                                                                      │
│      @Override                                                                                                                                                                                                                                                                       │
│      public Health health() {                                                                                                                                                                                                                                                        │
│          int active = taskExecutor.getActiveCount();                                                                                                                                                                                                                                 │
│          int max = taskExecutor.getMaxPoolSize();                                                                                                                                                                                                                                    │
│                                                                                                                                                                                                                                                                                      │
│          if (active >= max) {                                                                                                                                                                                                                                                        │
│              return Health.down()                                                                                                                                                                                                                                                    │
│                      .withDetail("activeThreads", active)                                                                                                                                                                                                                            │
│                      .withDetail("maxThreads", max)                                                                                                                                                                                                                                  │
│                      .build();                                                                                                                                                                                                                                                       │
│          }                                                                                                                                                                                                                                                                           │
│          return Health.up().build();                                                                                                                                                                                                                                                 │
│      }                                                                                                                                                                                                                                                                               │
│  }                                                                                                                                                                                                                                                                                   │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  Configure the readiness probe in the deployment:                                                                                                                                                                                                                                    │
│                                                                                                                                                                                                                                                                                      │
│  ```yaml                                                                                                                                                                                                                                                                             │
│  readinessProbe:                                                                                                                                                                                                                                                                     │
│    httpGet:                                                                                                                                                                                                                                                                          │
│      path: /actuator/health/readiness                                                                                                                                                                                                                                                │
│      port: 8080                                                                                                                                                                                                                                                                      │
│    initialDelaySeconds: 10                                                                                                                                                                                                                                                           │
│    periodSeconds: 5                                                                                                                                                                                                                                                                  │
│    timeoutSeconds: 2                                                                                                                                                                                                                                                                 │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  A saturated service will be removed from load balancer rotation immediately instead of causing 504s.                                                                                                                                                                                │
│                                                                                                                                                                                                                                                                                      │
│  ---                                                                                                                                                                                                                                                                                 │

│      threshold: "0.8"                                                                                                                                                                                                                                                                │
│  ```                                                                                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                                                                                      │
│  At minimum, set CPU and memory HPA:                                                                                                                                                                                                                                                 │

│  ### Fundamental Root Cause                                                                                                                                                                                                                                                          │
│  The fundamental root cause is that `payments-service` lost the ability to make progress on incoming requests in a timely manner due to **resource exhaustion** and **blocking dependencies**. The most likely mechanism:                                                            │
│                                                                                                                                                                                                                                                                                      │
│  1. `payments-service` uses a thread‑per‑request model.                                                                                                                                                                                                                              │
│  2. Each request performs synchronous, blocking I/O to a downstream dependency (e.g., database, cache, external payment provider).                                                                                                                                                   │
│  3. At incident time, one or more dependencies became slow or stalled.                                                                                                                                                                                                               │
│  4. The downstream call had no effective internal timeout, so worker threads did not release—they waited indefinitely.                                                                                                                                                               │
│  5. As more requests arrived, all available worker threads became occupied, and new requests could not be processed.                                                                                                                                                                 │
│  6. The service may have still passed health checks, but it could not handle current traffic.                                                                                                                                                                                        │
│  7. The API gateway waited 30 seconds, received no response, and returned a 504.                                                                                                                                                                                                     │
│                                                                                                                                                                                                                                                                                      │
│  This is an **architectural/code‑level failure mode**:                                                                                                                                                                                                                               │

│  - **No backpressure or bulkheading**: No separation between different request types or dependencies.                                                                                                                                                                                │
│  - **Gateway timeout not aligned**: The 30s timeout may be longer than the service’s actual performance budget, allowing request pile‑up.                                                                                                                                            │
│  - **Autoscaling not triggered**: The service may not have had enough replicas to handle the load before saturation.                                                                                                                                                                 │

│  > `payments-service` became unable to respond within 30 seconds because its request‑handling capacity was exhausted by worker threads blocked on a slow/unresponsive downstream dependency, and the service lacked the necessary timeout, circuit‑breaking, and isolation controls  │
